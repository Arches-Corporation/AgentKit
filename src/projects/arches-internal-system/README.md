# arches-internal-system pack

Reserved project pack for `Arches-Corporation/arches-internal-system`. Empty by design — this repo's
team adds its own project-specific guardrails/skills here. See AgentKit
`docs/developing.md` (add-a-pack walkthrough). A consumer opts in with
`"project": "arches-internal-system"` (or `agentkit init --project arches-internal-system`); shared-tier assets apply
regardless.
