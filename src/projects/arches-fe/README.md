# arches-fe pack

Reserved project pack for `Arches-Corporation/arches-fe`. Empty by design — this repo's
team adds its own project-specific guardrails/skills here. See AgentKit
`docs/developing.md` (add-a-pack walkthrough). A consumer opts in with
`"project": "arches-fe"` (or `agentkit init --project arches-fe`); shared-tier assets apply
regardless.
