Reserved project pack for `Arches-Corporation/b2b-survey`. Empty by design — this repo's
team adds its own project-specific guardrails/skills here. See AgentKit
`docs/developing.md` (add-a-pack walkthrough). A consumer opts in with
`"project": "b2b-survey"` (or `agentkit init --project b2b-survey`); shared-tier assets apply
regardless.
